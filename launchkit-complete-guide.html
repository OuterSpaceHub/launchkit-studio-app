LaunchKit Complete Guide

LaunchKit Studio App

This document collects the app setup, deployment checklist, SaaS guide, digital product plan, and launch instructions in one place.

1) What this project is

This repo contains a production-style starter for two monetizable products:

  • SaaS MVP: LaunchKit page builder for founders and startups.
  • Digital product bundle: launch assets and templates that can be sold separately.

The app includes:

  • landing-page marketing site
  • page builder/editor
  • dashboard with saved pages
  • public pages at /[slug]
  • Stripe checkout and billing scaffolding
  • digital bundle in products/launchkit-bundle

2) Product strategy

2.1 SaaS MVP idea

LaunchKit helps founders turn ideas into polished launch pages without design friction.

  • Build pages from reusable blocks
  • Preview changes instantly
  • Publish a live page with its own slug
  • Manage subscription billing

2.2 Digital product bundle

The digital product bundle can be sold separately on Gumroad, Shopify, or your own storefront.

  • landing-page templates
  • messaging notes
  • sales copy
  • product template bundle

4) Local setup

Install

npm install
npm run dev --workspace=apps/web

Open routes

  • http://localhost:3000
  • http://localhost:3000/editor
  • http://localhost:3000/dashboard
  • http://localhost:3000/auth
  • http://localhost:3000/checkout

5) Required environment variables

NEXT_PUBLIC_SUPABASE_URL=https://<project-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<supabase-anon-key>
SUPABASE_SERVICE_ROLE_KEY=<supabase-service-role-key>

STRIPE_SECRET_KEY=sk_live_xxx
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_xxx
STRIPE_PRICE_ID=price_xxx
STRIPE_WEBHOOK_SECRET=whsec_xxx
Keep service-role and secret keys server-only. Do not expose them in client code or public files.

6) Supabase setup

  1. Create a Supabase project.
  2. Go to Project Settings → API.
  3. Copy Project URL and anon key.
  4. Copy service role key.
  5. Run the SQL migration files:
supabase/migrations/001_init.sql
supabase/migrations/002_rls.sql

Tables created

TablePurpose
customersMap Supabase users to Stripe customers
subscriptionsTrack recurring billing state
pagesStore page blocks and published state

7) Stripe setup

  1. Create a product in Stripe Dashboard.
  2. Create a recurring price.
  3. Copy the price ID into STRIPE_PRICE_ID.
  4. Copy the secret/public keys into the env vars.
  5. Create a webhook endpoint:
https://<your-vercel-domain>/api/stripe/webhook

Listen for:

  • checkout.session.completed
  • customer.subscription.created
  • customer.subscription.updated
  • customer.subscription.deleted
  • invoice.paid
  • invoice.payment_failed

8) Deployment checklist (Vercel)

  1. Connect the repo to Vercel.
  2. Import the GitHub repo.
  3. Set framework to Next.js.
  4. Add env variables in Vercel Project Settings → Environment Variables.
  5. Deploy from main.
  6. Verify the app loads.
  7. Validate auth, page save, public slug route, and checkout flow.

Recommended domain flow

  • Use a Vercel domain initially
  • Then connect a custom domain
  • Use HTTPS automatically provided by Vercel

9) How the page builder works

  1. Open /editor.
  2. Add blocks: hero, features, CTA.
  3. Edit each block’s content.
  4. Preview changes in the live preview panel.
  5. Save content to the database.
  6. Toggle “Publish live” and save.
  7. Open the page from the dashboard or via /{slug}.

Published pages render through the public route /[slug].

10) Billing flow

The project includes:

  • /checkout page for subscription start
  • stripe checkout endpoint
  • webhook handler to update customer and subscription records
  • /settings page for customer billing portal access

When Stripe sends the checkout completed event, the app attempts to write the customer/subscription records into Supabase.

13) Security notes

  • Never expose service role keys in browser code.
  • Use RLS policies in Supabase.
  • Validate webhook requests with Stripe signatures.
  • Do not ship with broad public database access.
  • Check logs in Vercel and Stripe regularly.
